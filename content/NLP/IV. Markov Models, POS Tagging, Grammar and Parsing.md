### Q26: Show the equation that would be used to compute the probability of *P(PRP NN RB VBZ NN* | *My dog also eats spinach*) using a bigram POS tagger
###### Solution:

The probability `P(PRP NN RB VBZ NN | My dog also eats spinach)` using a trigram POS tagger is computed as:

`P(My | PRP) * P(PRP | φ<sub>1</sub>) * P(dog | NN) * P(NN | PRP)`  
`* P(also | RB) * P(RB | NN) * P(eats | VBZ) * P(VBZ | RB)`  
`* P(spinach | NN) * P(NN | VBZ)`

### Q: Why is direct estimation of the most likely tags given an observed word sequence,  
T₁...Tₙ = argmax P(T₁...Tₙ | W₁...Wₙ), not practical? What is the time complexity of direct estimation assuming a total of k tags? What technique/algorithm is used to get around the problem? [2 + 2]

**Solution:**  
Direct estimation is exponential in terms of the number of past n-grams whose tags we want to predict. Its complexity is **O(kⁿ)**, making it inefficient. The **Viterbi algorithm**, which is an instance of dynamic programming, is used to overcome this problem.

### Q: Explain briefly the 3 main problems in an HMM? What technique is used for each? [3 + 3 + 3 + 3 = 12 points]

**Solution:**  
1. **Compute the probability of an observation sequence \(O<sub>1</sub>, O<sub>2</sub>, ..., O<sub>n</sub>\)** given model parameters \(λ\), i.e., \(P(O<sub>1</sub>, O<sub>2</sub>, ..., O<sub>n</sub> | λ)\).  
   **Technique:** Forward-Backward algorithm.

2. **Find the optimal state sequence the model went through** for a given observation sequence and model parameters \(λ\).  
   **Technique:** Viterbi algorithm.

3. **Find the optimal model parameters \(λ = (A, B, π)\)** that maximize the likelihood of observations \(P(O | λ)\).  
   **Technique:** Baum-Welch (EM) algorithm.

### Q: What is phrase chunking? How is it related to syntactic parsing? [2 points]

**Solution:**  
Phrase chunking refers to an analysis of a sentence that identifies the constituents (e.g., noun groups, verbs, verb groups, etc.) but does not specify their internal structure.  
Syntactic parsing, on the other hand, refers to the analysis of language based on grammar rules and focuses on the construction of complete parse trees for sentences.  
Thus, chunking is a sub-task of complete syntactic parsing, and it is often called **shallow parsing**.

### Q: What is ambiguity in parsing?  
Assume you are given a probabilistic Context Free Grammar (PCFG) and there are multiple parse trees for a sentence. How would you decide which parse tree is the most likely parse of the sentence? [2 + 2 = 4 points]

**Solution:**  
Ambiguity in parsing refers to deciding between two or more parse trees that are allowable (derivable or generated by) the given grammar of the language/corpus.  

**Using PCFG:**  
The probability of a sentence/derivation is computed using the product of probabilities of all its productions. This probability is used to rank or disambiguate different parse trees for a given sentence.  
Usually, the parse tree with the **highest probability** among all possible trees for the same sentence is considered the most likely parse tree for that sentence.

### Q: Briefly state the difference between top-down and bottom-up parsing. [2 points]

**Solution:**  
1. **Top-down parsing:**  
   - Begins with the start symbol of the grammar and tries to construct the parse tree by expanding production rules to match the input sentence.
   - Focuses on deriving the sentence by predicting the structure first.

2. **Bottom-up parsing:**  
   - Starts with the input sentence and tries to construct the parse tree by matching it to the grammar rules.
   - Focuses on assembling the structure from the sentence upwards.
### Q: What is a Context Free Grammar (CFG). Define formally? How does it differ from a probabilistic CFG? State one important task that can be done by PCFGs but not by CFGs. [3 + 2 + 2=7 points]

Sol. A Context Free Grammar (CFG) is a formalism/grammar for generating language. It contains a set of terminals, N (which are usually words) and non-terminals, Σ (which are usually POS tags/Chunks), and a set of rules or productions of the form A→β, where A is a non-terminal and β is a string of symbols from Σ ∪ N.

A PCFG is a probabilistic version of a CFG where each production must add to 1, defining a distribution for each non-terminal. Probabilities of all productions rewriting a given non-terminal must sum to 1.

PCFGs can disambiguate between multiple parse trees for a given sentence however this cannot be done directly using a CFG.
